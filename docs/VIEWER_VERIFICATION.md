# Viewer verification record

`tests/test_phase6_viewer.py` covers the markup contract (no external `src`/
`href` attributes, payload sourced from log rows, sign-off gate, tamper
refusal). It deliberately does **not** grep for `fetch(` or `@import`: the
vendored three.js body contains those strings inside `FileLoader` and shader
code this viewer never calls, so a substring scan proves nothing either way.

"Makes no network requests" is therefore verified **empirically**, by loading
a generated viewer in a real browser and reading its network log.

## Procedure

```bash
python -m http.server 8765 --directory <dir containing viewer.html>
```

Open `http://localhost:8765/viewer.html`, then read the browser's network
panel and console.

## Result — 2026-08-23, CalculiX-validated demo part `P0001@v2`

Generated by the full pipeline demo (cantilever arm, fail at SF 0.67 →
referenced fix → pass at SF 1.53 → sign-off → BOM → viewer).

**Network requests: exactly one — the document itself.**

```
[94DC4B08D0B1F2E16962AD6A994EFAB7] GET http://localhost:8765/demo_viewer.html → 200 OK
```

**Console: no messages** (no errors, no warnings).

**Renderer state**, read live from `window.__designEngineViewer`:

| Check | Value |

| three.js revision | 147 (vendored, MIT) |
| WebGL context | WebGL 2.0 (OpenGL ES 3.0 Chromium) |
| Canvas | 1600 × 900 |
| Triangles drawn per frame | 788 |
| Draw calls | 5 |
| Part triangles in payload | 268 |
| `camera.up` | `[0, 0, 1]` — CAD Z-up preserved, not three.js default Y-up |
| Scene contents | Mesh, LineSegments (edges), GridHelper, AxesHelper, Mesh (stress marker), 3 lights |

**Peak-stress marker placement** was checked against physics, not just
presence: the marker sits at `(-8, 5, 0)` mm. The part is 16 mm deep in x
(centred, so x spans −8…+8), fixed at z = 0, loaded in +x at the tip. Maximum
bending stress therefore belongs at the root (z = 0) on the extreme fibre
(x = −8). That is where the log put it and where the viewer draws it.

**Panel contents** matched the log exactly — signer, statement, token, safety
factor 1.53, material source string, BOM totals and the `proof-of-concept`
budget label.

## Re-verifying

Re-run after any change to `viewer.py`, `data/viewer_template.html`, or the
vendored three.js. The `window.__designEngineViewer` handle exposes
`payload`, `scene`, `camera`, `renderer`, `mesh` and a `frames` counter for
exactly this purpose.
